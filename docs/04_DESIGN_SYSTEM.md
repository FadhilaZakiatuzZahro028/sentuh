# 04 — UI/UX Design Principles

## Positioning
Sentuh should feel like a restrained, credible physical-product brand, not a generic AI-generated SaaS template. The actual acrylic stand (original photography when available) is the hero. The website's purpose is clear conversion and a frictionless mobile page, not decoration.

## Starter visual tokens (subject to real UI review)
- Brand dark / forest ink: `#1D2723`
- Warm off-white canvas: `#F6F7F3`
- Muted sage: `#69736A`
- Restrained accent: `#C5E19A` (small highlights; test contrast before text use)
- Typography: a well-supported, intentional sans serif; choose final fonts with licensing/performance in mind.
- Consistent spacing scale, one coherent radius scale, strong hierarchy and ample whitespace.

## Do
- Build a real visual hierarchy: one clear headline, restrained supporting text, real product photo, a single primary CTA per section.
- Make mobile page the reference layout (many visitors arrive via QR/NFC).
- Make buttons large enough for fingers, show recognizable labels, use accessible contrast and visible focus states.
- Keep business customization limited to logo, cover, accent, tagline and ordered links; maintain template integrity.
- Ensure landing, admin and business pages are **purposefully distinct**, while sharing quality standards.

## Avoid
- Decorative purple gradients/glowing blobs, generic 3D illustrations, repeated identical cards, excessive rounded pills, arbitrary icons, wall-of-text heroes, fake review/testimonial sections, auto-playing motion.
- Google branding or star ratings implying affiliation/real reviews without permission/evidence.
- Complex admin form on one long page: group sections into identity, visual appearance, links, publication/preview.

## Primary screens
1. Marketing landing: hero, how it works, what is included, applicable use cases, transparent pricing/ordering and FAQ widget.
2. Admin: overview, business list + create/edit grouped form, device registration/QR, optional reporting.
3. Mobile business page: identity, short description, links, address and optional media.
4. Friendly unavailable destination and accessible empty states.

## Design review criteria
360px mobile width, common desktop width, accessible color contrast, intentional copy, no horizontal overflow, clear loading/error/empty states, functional keyboard navigation and link destinations. Verify with real screenshots instead of accepting a mockup at face value.
